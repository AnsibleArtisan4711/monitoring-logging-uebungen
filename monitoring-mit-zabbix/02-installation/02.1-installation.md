## Lernziele

Nach dieser Übung kannst du

- Datenbank anlegen und Schema in der richtigen Reihenfolge einspielen
- Server und Agent konfigurieren und starten
- Fehlerbilder (falscher Datenbankanschluss) im Protokoll erkennen
- Standardkennwort ändern und Laufzeitbefehle (`-R`) nutzen

## Hinweise

- Alle Namen, Adressen und Kennwörter sind Übungswerte (zum Beispiel `uebung-zbx`); verwenden Sie sie nicht außerhalb des Labors.
- Alle Dateien liegen unter `/tmp/p17`; die Ports 11050, 11051, 11161, 15432 und 18080 auf `127.0.0.1` müssen frei sein. Die Skripte setzen den gebauten Zabbix unter `/opt/zbx` voraus.
- Das Standardkennwort wird nur zur Übung verwendet und sofort geändert; in Produktion nie belassen.
- Der Zabbix-Server im Container läuft ohne systemd; unter systemd starten Sie ihn mit `systemctl` (nicht getestet).

## Musterlösung

<details>
<summary>Antworten und Zielzustand (erst nach dem Versuch öffnen)</summary>

1. Siehe `beispiele/installation.ausgabe.txt`: `schema.sql`, `images.sql` und `data.sql` werden eingespielt (203 Tabellen); die Datenbankversion in `dbversion` ist 7000000/7000030.
2. Mit Port 15999 meldet der Server `connection to database … failed … Connection refused` und beendet sich. Mit richtiger Konfiguration meldet er `current database version (mandatory/optional): 07000000/07000030` und `server #0 started [main process]`.
3. `zabbix_agentd -t`: `agent.ping` → `[u|1]`, `agent.hostname` → `lin01`, unbekannter Schlüssel → `ZBX_NOTSUPPORTED`.
4. Das Frontend braucht die PHP-Module `pgsql`, `bcmath`, `mbstring`, `gd`, `xml`, `curl`. Das Standardkennwort wird beim Anmelden akzeptiert (Token mit 32 Zeichen), danach geändert; das alte Kennwort wird abgelehnt.
5. Die `-R`-Befehle werden weitergeleitet („forwarded successfully“); ein unbekannter Befehl wird abgelehnt. Die Paketschritte (Repository-Paket, `apt install zabbix-server-pgsql …`) sind **nicht ausgeführt** und nicht bestätigt.

**Kontrollfragen (Antwortskizzen):**

1. `schema.sql`, `images.sql`, dann `data.sql`.
2. Im Protokoll steht `connection to database … failed … Connection refused`; der Server beendet sich.
3. Es testet einen Schlüssel ohne den Dienst zu starten (`agent.ping` → 1).
4. Nein; der Server wurde aus dem Quellcode gebaut, die Paketschritte in Schritt 7 sind Fachwissen und nicht bestätigt.

</details>
